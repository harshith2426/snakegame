# Test report evidence

This folder is reserved for the executed Part 3 evidence. The final reports are not present yet because the team must run the tests and record actual results first. Do not treat the planning guide or this placeholder as a completed test report.

When ready, add:

- `test-cases.md` — updated test cases, SRS links, actual results, and evidence.
- `unit-test-report.md` — automated test command, environment, results, failures, and logs.
- `system-validation-report.md` — requirement-to-test validation and observed outcomes.
- `code-coverage-report.md` — reproducible line/function coverage results.
- `branch-coverage-report.md` — reproducible branch results, separate from line coverage.
- `logs/` — raw test and coverage output needed to reproduce the reports.

Follow [Part 3 testing and report deliverables](../part3-testing-and-reports.md). Link the final reports from the root README after the team reviews the evidence.
